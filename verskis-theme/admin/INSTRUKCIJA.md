# Как залить дизайн `rankis2` на Verskis

Ничего из этого ещё не сделано: FTP-доступов нет, на боевой магазин не заливали. Порядок, когда доступы появятся.

## 1. FTP

1. Запросить у Verskis: pagalba@verskis.lt / +370 602 31006, тема «FTP prisijungimai dizaino šablonui (rankis.lt)».
2. Подключиться FileZilla (хост, логин, пароль из письма). В корне будут папки шаблонов (`sablonas3002`…, `rankis`, системные `admin`, `default`, `common`, `min` — их не трогать).
3. Загрузить папку `verskis-theme/rankis2/` целиком как `rankis2` (внутри `css/` с четырьмя файлами и `images/`). Имя папки латиницей, одним словом.

## 2. Переключение шаблона

1. Админка → Nustatymai → **El. parduotuvės išvaizda** → справа **Spalviniai šablonai**.
2. В списке появится `rankis2`. Выбрать, нажать **Išsaugoti**.
3. Нажать **Išvalyti greitintuvą** вверху админки. Открыть сайт в режиме инкогнито.
4. Откат: там же выбрать `rankis` и снова очистить кеш.

## 3. Блоки главной

El. parduotuvės išvaizda → вкладка **Titulinis puslapis**. Порядок блоков в центре:

1. **Tekstas pradiniame puslapyje** — вставить содержимое `hero.html` + `usp.html` (редактор в режиме HTML / «Šaltinis»). Это даёт тёмный hero с цифрами, жёлтые плитки и полосу преимуществ.
2. **Titulinio puslapio reklaminis plotas** (слайдер баннеров) — оставить, если нужны баннеры акций; иначе убрать.
3. Ещё один текстовый блок с `categories.html` — плитки категорий. Картинки и ссылки заменить на свои.
4. **Kategorijos prekės** — лента «Ypatingi pasiūlymai» (категория Išpardavimas), затем **Naujos prekės**.
5. **Gamintojai (centriniai blokai)** — полоса брендов.

Боковые блоки на главной убрать (дизайн на всю ширину). В **Bendri nustatymai** → «Prekių kiekis eilutėje» поставить 4 для категорий.

## 4. Логотип

Файл `rankis2/images/logo.svg` подставляется стилем вместо картинки из «Logotipas, ikona». Если нужен PNG-логотип из админки, в `style.css` удалить правило `#logo { background: url(../images/logo.svg) ... }` и `#logo img { display: none }`.

## 5. Проверка после включения

- Главная, категория с фильтрами, карточка товара, корзина, оформление заказа, поиск — на десктопе и телефоне.
- Если что-то поехало: сначала очистить кеш; если не помогло — переключить на `rankis` и прислать скриншот, правится в `style.css`.

## Что известно заранее

- Шаблон переопределяет системный CSS Verskis, разметка и JS остаются их. Мега-меню, фильтры, слайдер работают как раньше, только в новом виде.
- В локальном стенде (`npm run lab`) поверх ещё лежит старый шаблон `rankis`, поэтому часть правил с `!important`; в бою он отсутствует.
- Шрифты Archivo и Inter грузятся с Google Fonts через `@import` в `typography.css`.
