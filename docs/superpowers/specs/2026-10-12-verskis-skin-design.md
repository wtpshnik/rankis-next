# rankis.lt — скин для Verskis (дизайн из rankis-next)

Дата: 2026-10-12. Статус: подход утверждён пользователем в чате («поехали»). Деплой на Verskis НЕ делать: FTP-доступов нет, пользователь явно просил ничего не заливать.

## Цель

Перенести визуальный язык новой витрины (`rankis-next`, Next.js) на текущий магазин rankis.lt, работающий на Verskis, в виде шаблона дизайна Verskis: папка `rankis2/` с `css/color.css`, `css/style.css`, `css/forms.css`, `css/typography.css` и `images/`, плюс HTML-блоки и инструкция для админки. Результат должен выглядеть «как у нас сейчас на React» настолько, насколько позволяет фиксированная разметка Verskis.

## Ограничения платформы (см. память `project-verskis-design-templates`)

- HTML генерирует Verskis; свой JS добавить нельзя. Всё поведение (меню, слайдеры, фильтры) остаётся родным, меняется только вид.
- Шаблон = чистый CSS поверх системного `styles/common` (в бою компилируется в `css_all`). Текущий шаблон `rankis` при переключении на `rankis2` из сборки исчезает.
- Раскладка блоков страниц и HTML-содержимое блоков задаются в админке «El. parduotuvės išvaizda», HTML-блоки принимают произвольный HTML (без JS).
- Картинки шаблона лежат в `rankis2/images/` и адресуются из CSS как `../images/...`.
- Шрифты подключаем `@import` Google Fonts (Archivo + Inter) в `typography.css`.

## Стенд (без доступа к Verskis)

`verskis-theme/lab/serve.mjs` (Node, без зависимостей) на `localhost:4100` отдаёт снимки живых страниц из `verskis-theme/fixtures/*.html` (home, category, subcategory, product, cart, search, sale), подставляя `<base href="https://www.rankis.lt/">`, компилированный CSS Verskis из `verskis-theme/vendor/css_all.css` и следом четыре файла `rankis2/css/`. Картинки и JS грузятся с живого сайта. В стенде поверх нас лежит ещё старый шаблон `rankis` (он внутри `css_all`), поэтому там, где он мешает, используем `!important`; в бою его не будет.

## Что переносим из rankis-next (приоритет сверху вниз)

1. Токены: цвета `#0f0f10 / #6b7280 / #e6e7ea / #ffd400 / #f5f5f4`, Archivo для заголовков и цен, Inter для текста, радиусы 12–20 px, тень `0 18px 40px -20px rgb(15 15 16 / .28)`.
2. Шапка: жёлтая линия 4 px сверху, белый фон, лого, круглый поиск с жёлтой кнопкой, телефон с чёрным кружком, корзина со счётчиком-бейджем. Чёрная полоса меню: заглавные, жёлтое подчёркивание при наведении, выпадашка белая с мягкой тенью.
3. Карточка товара в списках: белая, рамка 1 px, радиус 16, подъём и тень при наведении, увеличение фото, бренд капсом мелко, название 2 строки, код, крупная цена Archivo, старая цена зачёркнута, бейдж скидки жёлтый круглый, точка наличия, кнопка «Į krepšelį» жёлтая круглая.
4. Главная: блоки «Titulinio puslapio reklaminis plotas» (hero, HTML из `admin/hero.html`), «Tekstas pradiniame puslapyje» (полоса преимуществ, `admin/usp.html`), плитки категорий (`admin/categories.html`), ленты «Ypatingi pasiūlymai»/«Naujos prekės» в нашем стиле, бренды в полосе (CSS-marquee на `@keyframes`), заголовки секций с жёлтой чертой.
5. Страница товара: галерея на светлом фоне со скруглением, блок цены как карточка с тенью и липким позиционированием, кнопка покупки жёлтая крупная, таблица характеристик зеброй, табы описания как подчёркнутые вкладки.
6. Категория: хлебные крошки, заголовок Archivo, чипсы подкатегорий, фильтры слева в белых карточках, сортировка/вид селектами в нашем стиле, пагинация круглыми кнопками.
7. Корзина и формы: таблица позиций в карточке, итог справа карточкой, инпуты 44 px со скруглением 10 px и фокусом чёрной рамкой.
8. Футер: чёрный, с зерном, большой жёлтый телефон, колонки ссылок, нижняя строка.
9. Мобильная версия: Verskis сам адаптивный; доводим отступы, размеры карточек (2 в ряд), меню-бургер в нашем стиле. Нижней панели не будет (нужен JS).

## Файлы

- `verskis-theme/rankis2/css/{color,typography,forms,style}.css` — шаблон. `style.css` разбит комментариями по секциям (reset-overrides, header, nav, cards, home, product, category, cart, footer, responsive).
- `verskis-theme/rankis2/images/` — логотип (SVG/PNG), плейсхолдер, спрайт не используем.
- `verskis-theme/admin/*.html` — HTML-блоки для главной (hero, usp, categories) с инлайновыми классами из `style.css`.
- `verskis-theme/admin/INSTRUKCIJA.md` — пошагово: FTP, переключение шаблона, раскладка блоков, вставка HTML-блоков, очистка кеша, откат.
- `verskis-theme/lab/serve.mjs`, `verskis-theme/fixtures/`, `verskis-theme/vendor/` — стенд.
- `package.json`: `"lab": "node verskis-theme/lab/serve.mjs"`.

## Проверка

- Стенд открывается на 7 страницах без ошибок в консоли, кроме внешних (reCAPTCHA/аналитика).
- Скриншоты каждой страницы на 1280 и 375 px сравниваются с rankis-next глазами: шапка, карточка, цена, кнопки, футер совпадают по токенам.
- CSS проходит `npx stylelint`? Нет, не добавляем зависимость: проверка синтаксиса через `node -e` с парсером браузера не нужна; достаточно отсутствия ошибок парсинга в DevTools (`document.styleSheets[...].cssRules` читаются).
- Playwright-смоук не пишем: стенд и так проверяется вручную, а поведение не наше.

## Вне объёма

Любая загрузка на Verskis, изменение настроек админки, JS-поведение, новые страницы, перенос контента.
